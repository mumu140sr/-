はじめに

まずここだけ読んでください

できること

条件を入力すると、コンピュータが数学的に最も条件に合うシフトを自動で組みます。人手で総当たりするのとは違い、「これ以上良い組み合わせは存在しない」ところまで計算します。

必要なもの

パソコンとブラウザ（Chrome / Edge など）だけです。インストールもログインも不要。上のURLを開けばすぐ使えます。スマホでも開けますが、表が広いのでパソコンを推奨します。

データの置き場所

入力したデータはそのパソコンのブラウザの中に保存されます。外部には一切送信されません。裏を返すと別のパソコンとは共有されません。

いちばん大事な注意

データはブラウザに保存されているだけです。ブラウザの履歴・サイトデータを消すと全部消えます。また 🗑 リセット ボタンは全データを消すボタンです。押す前に必ず確認してください。作ったシフト表は毎月 Excelに出力して保存しておけば、消えても内容は残ります。

画面の構成

左側に ①基本設定 → ②シフト種別 → ③スタッフ管理 → ④希望休入力 → ⑤自動生成 → ⑥シフト表 の6つのタブがあります。この番号順に進めば完成します。

①〜③は「一度決めたら基本そのまま」の設定です。毎月さわるのは ④ → ⑤ → ⑥ の3つだけだと考えてください。

共通の操作

  • 入力すると自動で保存されます。念のため区切りで 💾 保存 を押すと確実です。
  • 画面が暗いほうが見やすい人は右上の 🌙 で明暗を切り替えられます。
  • 表の見出しの境目をドラッグすると列の幅を変えられます。文字が見切れるときに使ってください。
◎

毎月の作業

来月分を作るときの手順。慣れれば10分ほどです

  1. 1①基本設定で「対象年月」を来月に変える変えると「前月末の連勤を取り込みますか？」と聞かれます。前月のシフトが画面にある場合は「はい」を選んでください。月をまたぐ連勤や休みのつながりが正しく計算されます。
  2. 2③スタッフ管理で人の増減・公休数・有給を確認する入退社があった月だけ。無ければ飛ばして構いません。
  3. 3④希望休入力に、集めた希望休をすべて入力するここが唯一の手入力作業です。ここを丁寧にやれば後が楽になります。
  4. 4⑤自動生成の 🔍 実現性チェック を先に押す「そもそも人手が足りているか」を生成前に判定します。🚨が出たら、生成しても必ずエラーが残ります。先に公休数や必要人数を見直してください。
  5. 5🚀 シフト自動生成を実行 を押して待つふつうは数秒〜数十秒。計算中も他の画面は触れます。1部門あたり最大10分で打ち切ります。
  6. 6⑥シフト表で結果を確認し、必要なら手で微調整するエラーが残っていたら「エラー対処表」を見てください。
  7. 7📥 Excelエクスポート で出力して保存・配布するこれで完了です。ファイルは必ず保管してください。
迷ったらこの順番

年月を変える → 希望休を入れる → 実現性チェック → 生成 → Excel出力。この5つだけで毎月のシフトは作れます。

①

基本設定

店舗全体の共通ルール。最初に一度決めれば、あとは毎月「対象年月」を変えるだけ

項目意味と決め方
対象年月作りたい月。毎月ここだけ変えます。変更時に前月末の連勤を取り込むか聞かれます。
連勤上限何日続けて出勤してよいか。4にすると5連勤以上が禁止になります。
遅→早の禁止遅番の翌日に早番を入れないルール。ONを推奨します。
単発休みのペナルティ出勤に挟まれた1日だけの休みを避けます。ONを推奨します。
連休の目安回数全員に月何回2連休を入れたいか。0＝指定なし。個人設定があればそちらが優先されます。
特別日設定入れ替え日・新装日を日付で入力すると、副店長がその日の責任者に固定されます。

ルールごとの強弱（重要）

この画面の 🎚️ ルールごとの強弱 を開くと、ルールを1つずつ調整できます。エラーが多すぎて困るときの調整弁です。

設定意味使いどころ
🔴 絶対必ず守る労務上ゆずれないルール
🟡 できればなるべく守る。守れなくても表は完成する理想だが妥協できるルール
OFFそのルールを一切見ない自店では不要なルール
安全のため変更できない4つ

人員不足・公休数不足・連勤超過・担当外シフトは、店舗が回らなくなるため常に「絶対」で固定されています。

一部のルールには数値も付いています。連休が長すぎるは「上限◯日まで」、早遅バランスは「許容◯日までのずれは許す」を設定できます。

シフト種別マスター

シフトの種類と「1日に何人必要か」を決める画面

初期状態では次の7種類が入っています。名前・色・人数は自由に変えられます。

記号名称区分役割
早責早番責任者早番系その時間帯に1人だけ。2人以上入るとエラー
遅責遅番責任者遅番系同上
早総務早番総務早番系同上
遅総務遅番総務遅番系同上
早早番早番系一般
遅遅番遅番系一般
研研修早番系必要人数には数えません（頭数の外）
カテゴリ A / B とは

A＝早番系、B＝遅番系です。「連勤中に早番と遅番を混ぜない」「遅番の翌日に早番を入れない」といったルールは、すべてこのA・Bで判定しています。新しいシフトを追加したら必ずどちらかを正しく選んでください。

必要人数（定数）

各シフトの「必要人数/日」が、その日に必ず入れたい人数です。社員とキャストで別々に設定できます。

アプリはこの人数をちょうどに合わせようとします。人が余った場合は、多く入れるのではなく休み（余＝余剰）に回します。

日別必要人数

📅 日別必要人数 を開くと、特定の日だけ人数を変えることができます。土日や繁忙日に使ってください。空欄の日は上の通常人数が使われます。

ここは効きすぎます

土日だけ増やしたつもりでも、月10日ぶん×2人＝20人日の追加になります。人員不足エラーの最大の原因がここです。エラーが多いときは真っ先に見直してください。

③

スタッフ管理

一人ひとりの条件。ここの精度がシフトの品質を決めます

列意味
部門社員／キャスト。キャストは連勤やリズム系のルールが免除されます（部分勤務では自然に起きるため）。
役職副店長／チーフ／リーダー／スタッフ。副店長が2人以上いる場合、毎日必ず1人は出勤するよう組まれます。
担当シフト最重要。この人が入れるシフトすべてにチェック。ここに無いシフトは絶対に割り当てられません。
スキル下の「スキル設定」で登録した資格・技能。「早番に営業できる人が最低2人」のような条件に使います。
公休数その月の休みの目標日数。ここに数えるのは 休 公 ☆ だけです。有給や季節休暇は別枠なので含めません。
有給その月に消化させたい有給日数。指定すると自動で 有 を配置します。
希望（早可/遅可）本人が入れる時間帯。片方のチェックを外すと、その時間帯を避けて組みます。
早遅バランス出勤日のうち早番と遅番の割合。指定なし（OFF）を選ぶとその人は判定しません。
連勤上限この人だけの上限。空欄なら①の全体設定に従います。
遅→早は連休必須遅番から早番へ移るとき、休み1日ではなく2連休を挟みます。
土日休み希望なるべく土日を休みにします。
休み方休みをまとめる（連休）か、こまめに散らすか。
連休回数この人だけの月の2連休の目安回数。空欄なら全体設定。
前月末連勤日数前月の最終日まで何日続けて出勤していたか。0＝月末は休みだったという意味です。
前月末シフト前月最終日が早番だったか遅番だったか。連勤日数が0のときは選べません（休みだったので存在しないため）。

早遅バランスの読み方

「早番多め（7：3）」は、出勤日のうち早番7割・遅番3割という意味です。日数ではなく割合なので、公休や有給が変わっても設定し直す必要はありません。

設定出勤20日なら出勤15日なら
早番多め（7：3）早14日 / 遅6日早10〜11日 / 遅4〜5日
早番やや多め（6：4）早12日 / 遅8日早9日 / 遅6日
均等（5：5）早10日 / 遅10日早7〜8日 / 遅7〜8日
遅番やや多め（4：6）早8日 / 遅12日早6日 / 遅9日
遅番多め（3：7）早6日 / 遅14日早4〜5日 / 遅10〜11日
指定なし（OFF）この人はバランスを一切見ません

割合はきれいな整数にならないため、「許容◯日までのずれは許す」（①のルール設定・初期値2日）でどこまで厳しく見るかを決めます。厳しくするほどエラーが増え、計算も長くなります。迷ったら2日のままで問題ありません。

前月末の取り込み

前月のシフト表が画面に出ている状態で 🔁 前月末の連勤・シフトを取り込む を押すと、全員ぶんの「前月末連勤日数」と「前月末シフト」が自動入力されます。手入力より確実なのでこちらを使ってください。

ここを空欄にすると月初がおかしくなります

前月末の情報が無いと、アプリは「前月末は休みだった」と判断します。実際には連勤中だった人が月初にさらに出勤してしまい、連勤オーバーや単発出勤の原因になります。

④

希望休・固定シフト入力

毎月の唯一の手入力作業

上のボタンで入れたい記号を選び、カレンダーのマスをクリックすると入ります。ダブルクリックで消去できます。

種類入るもの効果
休系有給 休 半休その日は必ず休みになります
出勤系早責 遅責 早 遅 研 などその日はそのシフトで固定されます（動かせません）
クリア—入力を消してアプリに任せます
研修日はここで指定します

研 を入れた日は研修で固定されます。研修は早番の時間帯として扱われますが、必要人数には数えません。研修者がいる日も、通常どおりの人数が別に配置されます。

入れすぎに注意

希望休を公休の目標日数より多く入れると、その人は必ず公休オーバーになります。また出勤シフトを固定しすぎると、アプリが調整できる余地が無くなりエラーが増えます。固定は本当に動かせない日だけにしてください。

自動生成

ボタンは2つ。必ず先に「実現性チェック」を押してください

先に：実現性チェック

🔍 実現性チェック は生成する前に、必要な人手と出せる人手を計算して足りているかを判定します。

表示意味やること
🚨 赤人手が構造的に足りない。どう配置してもエラーは消えません生成する前に、必要人数・公休数・有給日数のどれかを緩める
🟡 黄ぎりぎり足りているが余裕がないそのまま生成してよい。エラーが出たら設定を見直す
✅ 緑余裕ありそのまま生成

生成する

🚀 シフト自動生成を実行 を押します。多くの場合は数秒〜数十秒、条件が複雑だと数分かかります。1部門あたり最大10分で打ち切ります。計算中も他のタブは操作できます。

終わったときのメッセージ

表示意味やること
✅ 計算完了これ以上良い組み合わせは存在しないと確認済み。残ったエラーは今の設定では避けられません設定を見直すか、手で微調整する
⏱ 時間切れ10分では解ききれなかった。もっと減らせる可能性があります表示される ⏳ 妥協なしで再計算 を押すか、条件を緩める
「エラーが残った＝失敗」ではありません

✅が出ているなら、それが今の人員でできる最良の答えです。エラーを減らしたいときは、シフトの並べ方ではなく設定側（必要人数・公休数・希望休）を見直してください。

困ったとき

よくある質問

設定した人数より多く出勤している日があります

必要人数を超えないよう組まれるはずなので、まず日別必要人数でその日だけ増やしていないか確認してください。それでも多い場合は、④で出勤シフトを固定している人がいないか見てください。固定された人は人数調整の対象外になります。

月初がおかしい（いきなり単発出勤・連勤オーバーになる）

③の前月末連勤日数の入力漏れがほぼ確実な原因です。前月のシフト表を表示した状態で 🔁 前月末の連勤・シフトを取り込む を押して、自動入力し直してください。

実現性チェックは大丈夫だったのにエラーが出ました

実現性チェックが見ているのは「人手の総量が足りているか」だけです。総量が足りていても、特定の日・特定の役職に偏りがあるとエラーになります。エラーの内容から個別に対処してください。

生成が遅い／10分かかります

ルールを「絶対」にするほど時間がかかります。時間を短くしたいときは、①のルール設定で優先度の低いルールを「できれば」やOFFにしてください。なお、良い答え自体は序盤で見つかっていることが多く、残り時間は「これが最良だ」と確かめる作業に使われています。

手で直したところが、再計算で消えてしまいます

クリックで編集したマスは🔒固定されるので消えません。ドラッグで入れ替えただけのマスは固定されません。残したい場合は、そのマスをクリックして選び直してください。

別のパソコンで続きをやりたい

データはパソコンごとに保存されるため、そのままでは引き継げません。現状はExcelに出力して渡すのが確実です。作業自体は、新しいパソコンでURLを開いて設定を入力し直す形になります。

画面の文字が見切れています

表の見出しの境目をドラッグすると列の幅を変えられます。また表全体は左右にスクロールできます。ブラウザの拡大率（Ctrl と − ）を下げるのも有効です。

全部やり直したい

右上の 🗑 リセット で初期状態に戻せます。全データが消えますので、必要なものはExcelに出力してから実行してください。
